# SP-02 — 고급 검색 볼륨 선택의 API·UI 계약

Epic #1494 / 구현 #1496. 기준 `93a4cd7dec2` (SP-01 완료 상태).

## 원인과 범위

공통 SearchView는 volumeid와 boolean isencrypted를 같은 fetchVolumes 경로로 처리하면서 등록되지 않은 `listvolumes`를 호출하고 검색어도 `isencrypted`에 넣는다. 옵션 페이징·오류 표시·늦은 응답 보호가 없다. SP-01의 생성창과 다른 경로이다.

## 설계

1. volumeid만 전용 VolumeSearchSelect로 분리한다. `listVolumes(listall=true, keyword, page, pagesize=20)`의 서버 검색과 명시적 더 보기/목록 스크롤로 페이지를 조회한다. UUID를 value로 유지하고 VM·소유자/프로젝트·도메인·Zone·전체 UUID를 보조 텍스트로 표시한다. API keyword 계약 밖의 검색을 지원한다고 가정하지 않는다.
2. isencrypted는 기존 boolean switch로 유지하고 옵션 API를 호출하지 않는다. 적용 시 원래 boolean만 listVolumes에 전달하고 URL의 `true`/`false`도 boolean으로 복원한다. SearchView의 다른 선택기와 스토리지 스냅샷의 별도 SnapshotSearch 계약은 변경하지 않는다.
3. API 응답 envelope·count·페이지 크기·UUID 중복·소유 범위를 검사한다. 추가 페이지의 건수/중복 변화는 오류로 표시하고 재시도로 첫 페이지부터 다시 읽는다. 실패를 빈 결과로 표시하지 않는다. 초기 조회/검색/추가 조회/실패 중에는 상위 검색 제출을 차단한다.
4. 검색어 변경 즉시 이전 옵션을 지우고 세대를 무효화한다. 250ms debounce 후 새 조회를 시작하며, 최신 검색·소유 범위·로그인·권한·경로·마운트 세대와 일치한 응답만 적용한다. 입력 자체는 새 검색을 계속할 수 있게 유지하고 조회 중 옵션 선택을 차단한다.
5. 선택 UUID의 이름은 현재 범위 내 ID 조회로 복원한다. 접근 불가/삭제 대상은 UUID를 유지하며 경고와 제출 차단을 제공하고 선택 해제를 허용한다. 검색 결과가 바뀌어도 같은 범위에서 이미 확인한 선택 UUID를 임의로 다른 볼륨으로 바꾸지 않는다.
6. 부모의 범위 변경은 팝오버/선택을 닫고 초기화한다. 재설정은 선택기 세대를 새로 생성한다. URL 조건은 복사해 복원하며 고정 meta.params를 route.query에 직접 주입하지 않는다. 실제 UI에서 재현한 내부 `listall` 칩 노출을 방지한다. 필터 칩의 표시 이름은 범위가 적용된 ID 조회로 채우며 원래 UUID는 URL/API/해제에 유지한다.

## UI 표준

**컴퓨트 > 가상머신** 고급 검색의 세로 폼, 기본 AntD Select(32px/14px/4px), 재설정 왼쪽·검색 오른쪽의 기존 버튼 배치 및 테마 토큰을 준수한다. 공통 VM CSS와 툴바는 바꾸지 않는다. 보조 정보는 12px로 줄바꿈하며 기본 팝오버 폭 안에서 표시한다. 라이트/다크, 390/768/1280px에서 검색·선택·버튼 접근과 실제 PNG 크기를 확인한다.

## 완료 검증

- 실제 AntD Select와 SearchView/Autogen 연결: 이름 검색·중복 대상·페이지 2·빈 결과·지우기·선택/적용/칩 해제·재설정·URL 복원.
- 오류/재시도, 연속 검색 순서 역전, 페이지 변경, 사용자/프로젝트/권한 전환, 언마운트 및 접근 불가 ID.
- 볼륨 메뉴 isencrypted=true/false와 공통 선택기 소비 화면 회귀, SP-01 생성창 및 SnapshotSearch 회귀.
- 31 GFS2·32 RBD에 동일 production UI 배포 후 관리자·일반 소유자·다른 계정·프로젝트의 실제 API/UI 검증. 전용 개체로 목록 필터가 정확한 정책만 반환하는지 독립 DB와 대조한다.
- 정책/예약/볼륨/프로젝트/계정 등 시험 자원을 정상 API로 정리한다. 기존 자원·dirty FTCTL 폴더·WEB-INF/config/JAR/PID를 보존한다. 전체 Cloud/Maven/Actions/qemu 빌드는 범위가 아니다.
