# #1536 버킷 생성 저장소 선택 설계

## 원인과 계약

기존 CreateBucket는 표시 이름을 노출하지만 filterOption에서 UUID인 option.value만 toLowerCase로 비교했다. 재조회 때마다 첫 저장소를 선택했고, API 실패를 보호 기능 조회 오류로 표시해 미등록·실패·검색 결과 없음이 구별되지 않았다.

기존 listObjectStoragePools와 createBucket API를 사용한다. 서버·DB schema 변경은 없다. 저장소는 기존 API가 허용한 전역 등록 목록이며 선택한 버킷 소유 계정의 private 저장소 목록으로 오해하지 않는다. 사용자/프로젝트의 생성 소유자 결정·ACL·한도는 #1535/#1531 서버 계약을 유지한다.

## 검색과 식별자

bucketStoreSelection 유틸은 검색어·이름·UUID를 안전하게 문자열로 변환하고 NFKC·양끝/연속 공백·대소문자를 정규화해 부분 검색한다. 이름이나 UUID를 검색해도 실제 선택값과 createBucket.objectstorageid는 원래 UUID다. 같은 이름의 서로 다른 UUID를 합치지 않는다. 옵션에 이름과 UUID를 함께 표시하고 선택 후에도 UUID를 별도로 제공한다. 이름 변경·목록 순서·검색어 변경은 유효한 UUID를 바꾸지 않는다.

## 조회 상태와 선택 수명

- idle/loading: 저장소 선택·생성 제출을 막고 확인 중임을 알린다. 이름과 소유자 draft는 유지한다.
- ready: 전체 페이지를 읽고 count·ID 중복·응답 형식을 검증한 목록이다. 실제 UUID가 목록에 있어야 제출할 수 있다.
- empty: 성공적으로 전체0개를 확인한 상태다. 미등록 안내와 목록 업데이트를 제공한다. 등록 API 권한이 있는 관리자에게만 기존 등록 메뉴 연결을 제공한다.
- error: 최초/재조회/권한/응답 불완전 실패를 미등록으로 바꾸지 않는다. 재시도를 제공하고 이전 UUID/draft를 보존하되 제출과 선택은 차단한다. 성공 재조회 후에도 남아 있는 UUID만 복구한다.
- no match: ready 목록에 대한 로컬 검색 결과가0인 상태다. 검색어를 지우면 전체 옵션을 복구하며 기존 UUID는 유지한다.

최초 성공 목록에 한해서만 첫 저장소를 기본 선택한다. 선택된 UUID가 삭제되면 명시적으로 해제하고 재선택 안내를 표시한다. 이후 재조회에서 다른 첫 저장소로 바꾸지 않는다. 최초 빈 목록 뒤 등록된 저장소도 명시적으로 선택한다.

20초 제한을 둔 page=1/pagesize=500 조회를 최대100페이지 수행한다. count 변화·중복·누락·유효하지 않은 응답은 부분 목록을 확정하지 않는다. 목록은 ID/이름/보호 capability로 투영하며 다른 속성을 UI 후보에 보관하지 않는다.

## 소유 범위·실패 복구

#1535의 Root/Domain admin 선택, 일반 사용자 본인 고정, 현재 프로젝트 고정, account+domainid 또는 projectid 단독 매핑을 유지한다. 저장소를 갱신해도 소유자를 다시 선택하지 않는다. 신원·역할·세션·프로젝트·조회 API 권한이 바뀌면 열린 폼을 폐기하며 generation/scope가 다른 늦은 목록과 제출 완료를 무시한다.

저장소 목록 대기/오류/삭제된 선택은 Ctrl+Enter와 직접 제출 guard에서도 차단한다. 제출 중에는 목록 업데이트를 막는다. 성공 재조회/선택 변경 시 실제 해당 UUID의 capability와 용량 확인을 다시 계산하며 미지원 암호화/버전/잠금 요청값을 정리한다. 목록 오류를 암호화/객체 잠금 오류로 오기하지 않는다.

실제 서버 createBucket의 최종 UUID 유효성·소유 ACL·제한·예약 검증은 유지한다. 전달 전 실패는 기존 draft/선택을 보존해 명시적으로 재시도한다. 전송 여부가 불명확한 단절이나 이미 queued job의 실패를 중복 생성 없는 자동 재시도로 처리하지 않는다.

## UI 기준과 검증

가상머신 메뉴의 공통 FormItem·32px/14px 조작·4px 선택기·label/icon 패턴을 따른다. 드롭다운의 긴 이름·UUID·검색 결과 없음은 줄바꿈하고 표준 theme token을 사용한다. 키보드 검색/방향키/Enter, 밝은 화면·다크모드·360/768/1280px, 실제 텍스트 대비와 모달 내부 스크롤/하단 접근을 검증한다.
