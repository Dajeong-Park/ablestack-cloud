# #1455 NFS 자체 점검 수정 — 진행 기록

ACL에 서버 IP를 추가하지 않습니다. 숫자 IP/CIDR로 제한된 정상 ACL이 모든 로컬 주소를 제외한 경우에는 로컬 mount 점검을 외부 클라이언트 확인 필요로 분류합니다. 실제 mount 결과는 확인되지 않았다고 표시하며 성공으로 꾸미지 않습니다.

로컬 IP 관측 실패, 해석할 수 없는 정책, 허용된 로컬 주소의 mount 실패와 다른 export/포트의 실패는 계속 실패입니다. 기존 경로·UUID·inode·mount 경계와 리스너 검증은 유지합니다. 최초 구조화된 NFS 실패 결과는 원복 전에 보존합니다.

API는 별도 localprobe 관측을 제공하고 VM 표준의 NFS 탭에는 허용된 클라이언트에서 실제 접속을 확인해야 한다는 안내만 추가합니다. 이 관측은 원하는 정책이나 ACL에 저장하지 않습니다.

배포 전 로컬 guest 회귀87개, Java/API17개, 신규 notice2개+기존 경로UI7개, UI lint를 확인했습니다. 실제 SystemVM에서는 두 포트 실제 mount, 원격 전용 ACL 무변경, 제외된 서버의 실제 접속 거부, 다른 포트의 mount 실패 유지 등4개를 확인했습니다. 최초 native harness는 NFSv4의 숨겨진 export가 ENOENT로 응답하는 것을 너무 좁게 판정해 수정했으며 제품 코드 변경으로 통과시킨 것이 아닙니다. 운영 불변·임시 자원 정리를 확인했습니다.

이 기록은 실환경 인수 완료를 뜻하지 않습니다. 빌드/서명·13번 배포·실제 UI와 클라이언트 검증 결과를 별도로 갱신합니다.
