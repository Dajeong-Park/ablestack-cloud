# 최종 UI 캡처 행렬

두 클러스터 × 시작/완료 검토·실패 재개 × light/dark × 390/768/1280의 24개 조건, 상단·영향 확인 48개 JPEG다. 실제 JPEG 형식·해상도·SHA256와 대응 JSON을 검사했다. 대화상자 가로 넘침 0, 푸터가 viewport 내부에 유지됐다. 점검한 안내·구획 제목·확인 문자는 14px이며 배경 합성 후 최저 대비는 7.13이다. 전체 UI의 접근성 인증 결과를 뜻하지 않는다.
