# 원본 UI 캡처

원본 JPEG **75장**. 기록83회 중 같은 이름의 마지막 캡처를 기준으로75파일을 게시했다. 실제 viewport와 JPEG decoded 치수·signature·SHA256을 검증했다. 표준 비교는 VM 목록/상세/NIC/연결창/breadcrumb, 주요 화면은 Internal LB 생성/할당/최종 backend·실제 부족 실패/프로젝트·읽기 전용이다. 별도 이미지 편집이나 생성 이미지는 사용하지 않았다.
