# Epic 63개 시나리오와 상세 탭 결과

2026-11-07에는 I02·S05·S07의 게스트 실행과 C07·L01·S01·S02·M02·O04의 특정 프로젝트 권한 실행을 반영했다. [DHCP·DNS·통신과 캡처](../guest-network-1569-guest-20261107/README.ko.md)

31 GFS2·32 Glue RBD의 전용 VirtualRouter VLAN 시험망으로 실행했다. 기본 역할은 관리자이며 역할 행에 확인한 추가 역할을 표시했다. 클러스터별 차이는 결과 열에 기록했다.

각 클러스터의 현재 집계는 실패 0, 부분 49, 미실행 5, 환경 차단 6, 적용 제외 3이다. 행 전체의 성공은 0개다. #1587~#1589 수정 후 역할 회귀를 확장했으며 새 결함 #1590·#1591·#1592를 발견했다. 2026-11-08 #1590의 LB NULL/NPE·편집 실패 복구를 구현하고 31·32에서 재검증했다. [#1590 최신 결과](../guest-network-1590-20261108/README.ko.md). 2026-11-08 #1592의 VM 요약/NIC 링크 판정을 통합하고 공유 회수·재부여·조회 실패 복구와 역할/UI를 재검증했다. [#1592 최신 결과](../guest-network-1592-20261108/README.ko.md). TF 기능은 미구성으로 적용 제외지만 가용성 API 오류는 별도 결함이다. [이전 역할·조건부 회귀](../guest-network-1569-regression-20261107/README.ko.md). 과거의 측정과 부분 통과를 전체 행 성공으로 대체하지 않는다.

2026-11-08 추가 역할 회귀에서 4개 허용 역할 × Isolated/L2/Shared × 31/32의 UI 생성 24건·NIC 연결 24건, 제한 4역할의 직접 API 거부 48건, 접근 범위 조회 32건을 확인했다. VNF/TF 조건부 읽기 34건도 확인했다. 생성 대화상자의 소유 문맥 표시 부족과 390px 다크 NIC 표 제목 겹침을 발견했다. C06은 양쪽 실패로 갱신했으며 전체 모바일을 통과로 처리하지 않는다. 기존 8 NIC와 운영 자원을 보존하고 새 망 24개·VM 2개(각 4 NIC)를 남겼다. [최신 역할·UI·조건부 결과와 캡처](../guest-network-1569-roles-20261108/README.ko.md).

2026-11-08 #1593에서 NIC 고정 작업 열에 기존 VM 볼륨 탭과 같은 테마 배경을 적용했다. 별도 API 수정 없이 31·32 정적 UI를 배포했고, 390/768/1280px 라이트/다크·표 수평 스크롤 좌우·6개 역할 버튼 가드·프로젝트 왕복·VM 목록/상세/대화상자를 확인했다. C06의 모바일 제목 겹침 실패는 해소됐으며 넓은 미실행 조건 때문에 행은 부분으로 유지한다. [#1593 구현·배포·검증·캡처](../guest-network-1593-20261108/README.ko.md).
