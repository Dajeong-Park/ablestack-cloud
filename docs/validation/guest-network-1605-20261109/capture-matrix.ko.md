# UI 캡처 목록

원본 JPEG 85장. 각 파일의 JPEG 시그니처·디코딩 치수·SHA-256을 확인했다. 기록된 실제 viewport와 반환 이미지 치수가 일치하는 캡처는 77장이다. 반환 이미지 4장은 치수가 달라 반응형 검증 근거에서 제외했으며 표에서 구분한다. 이미지를 편집하거나 확대 합성하지 않았다.

자동화 초반의 프로젝트 옵션 클릭 미완료·중간 전환 캡처는 진단 기록으로 구분했다. 최종 선택 성공은 keyboard/프로젝트 복귀 후 VM 재진입과 final-review-state를 기준으로 판단한다. viewport 변경 도구의 대상·반영 시점이 맞지 않은 시도는 성공 케이스에 포함하지 않았고, 실제 치수를 확인한 40개 리사이즈 케이스와 24개 IP 탭 케이스를 별도로 집계했다.
