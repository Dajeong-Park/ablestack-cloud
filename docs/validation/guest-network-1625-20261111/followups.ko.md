1. **#1625 구현·31/32 배포·범위 검증 완료**. AppCookie의 runtime/appsession 결함을 닫는다. upstream 동기화와 병합 결과물 모듈 배포도 이번 단계에 포함됐다.
2. **다음 구현 #1626**: 세션 고정 대화상자의 비동기 dispatch/job0/job1/job2/결과 미확인, 실패 초안 복구·같은 job 재조회·중복/닫기 방지·권한/프로젝트 변경을 UI에서 완성한다. 이번에 공통 스타일·값 복원·capability 계약을 선행 적용했으므로 기존 설계 중 해당 부분은 완료로 구분한다. 열린 설정 팝업 resize 좌표도 재현/범위 결정한다.
3. #1569 P07의 AppCookie·SourceBased·LbCookie·TCP/SSL·오퍼링·역할 조합을 #1626 결과와 통합한다. 현재 결과는 AppCookie 세부 범위 완료이며63행 전체 완료나 통합 회귀 종결이 아니다.
4. 준비된 VPN 역할·서비스 철회/복구와 다른 네트워크 유형의 잔여 통합 항목을 이어간다. 독립 VPN client2대, CRL/OCSP, Health Monitor 제공자 등 환경 조건은 사용자가 확인한 차단을 유지한다.
5. 요구 범위의 남은 검증·확대 시험 실패를 구분해 최종 판정한 뒤 #1569/Epic 종료 여부를 결정한다. Draft Epic PR1577과 기존 브랜치를 유지하고 이번 단계에서 PR/Epic을 병합·종료하지 않는다.

확인용 자원은 보관한다. LB backend 부하분산 측정은 제외한다.
